# Whole-buffer reads tool/check_whole_buffers.sh finds, one per line:
#   <path under vendor/pdf_oxide>::<fn>#<n>  # <class>: <why>
# `table` is a read of something whole by nature, and the why names its kind (a
# font program, a sampled function, a PostScript calculator function, an ICC
# profile, the CMap table, a DER certificate or the DSS, the xref stream, one
# object-stream member, a progressive JPEG raster, a JPX recompressed at full
# size, a JBIG2 stream and globals, a JPX codestream). `unreached` is a site no
# lane can reach, and the script proves it (a cfg gate that is off for the
# build, a Path parameter, or a name no file under src/host or lib/ mentions)
# instead of trusting the why. A read of anything else is bounded instead, and
# the script refuses any other word after the `#`.
